# 可视化布局编辑器

把当前开发项目中用户指定的页面区域变成可直接操作的真实布局编辑区。用户亲自摆放；Agent 提供工具、校验与可靠保存，不凭截图猜测最终坐标。

Skill 是开发工作流：在当前项目源码里实现或复用编辑器，启动该项目预览，让用户直接调整正在开发的页面。

## 适用范围（先判断）

- 必须能定位当前开发项目的工作目录/工作树、页面源码和指定区域；沿用本任务已有开发上下文。
- 页面链接仅用来定位和验证该项目的开发预览，不是可编辑性凭据。不能因为用户给了一个网址，就把它当作可改源码的目标。
- 只有外部网址、截图或设计参考时，先解释本 Skill 要在当前开发项目里接入，再询问对应项目/源码；不做代理、运行时注入、克隆外站或临时另造一个页面来替代。
- 用户说“让我试一下”时，打开当前项目已接入该能力的开发页；尚未接入则在该页源码完成接入。若存在多个无法区分的开发候选，只问要用哪一个，不自行选历史页或演示页。
- 编辑能力覆盖哪个区域，以当前开发任务和用户指定为准。操作不自动授权修改其他页面或发布线上。


## 先定位，再接入

1. 读取当前开发项目规则，核对当前工作树和预览服务对应同一份源码，再找到指定页面、区域根节点、现有编辑器、组件和 CSS。已给选择器/节点/页面时直接定位；仅当有多个无法区分的区域时，问一个明确的定位问题。
2. 在同一宽度查看原页面桌面和移动状态，列出“目标元素 → 现有组件/样式 → 本次允许变化”。复用已有实现，不重画周边页面。
3. 简短声明范围：只加入指定区域的位置、对齐、层级和编辑状态能力。保留文案、配色、字体、内容尺寸、动效、业务逻辑和区域外布局，除非用户点名修改。
4. 建立元素清单，覆盖区域内的文字、按钮、图片、图标、装饰、输入框和容器；不能只让少数预先硬编码的标题可拖。登记稳定 ID、父子关系、可见断点与图层上下文。组和内部元素均可选择，默认选最深的可编辑节点，面板提供选父级/子项；多选不得同时选祖先与后代造成双重位移。
5. 明确背景/辅助线是否为参照：已有参照默认锁定并显示在元素清单，提供解锁；用户点名“包括背景”时纳入范围。伪元素提供代理对象；SVG/Canvas/WebGL 的内部图元需专用适配，不能把可拖整个画布冒称内部每个物体可拖。范围要求到内部时，补适配或明确该项未完成。

实现前读取 [交互与数据规范](references/implementation.md)。验收时读取 [真实路径验收](references/acceptance.md)。

## 必须交付的交互

| 能力 | 用户可观察行为 |
| --- | --- |
| 区域内拖拽 | 点击选中、拖动改变 x/y，显示选框、坐标和参考线；鼠标和触摸可用。 |
| 精调 | x/y 数值输入；方向键微调，Shift 加大步长；输入框编辑文字时不拦截方向键。 |
| 相对区域对齐 | 左、水平居中、右、上、垂直居中、下；分别只改对应轴，可双轴居中。 |
| 元素相互对齐 | 多选后按指定关键元素，或选择组边界，对齐左/中/右及上/中/下；显示当前参照。 |
| 等距 | 三个以上元素可水平/垂直等距排列，固定两端；空间不足时解释，避免静默重叠。 |
| 图层 | 上移一层、下移一层、置顶、置底；面板可选被遮挡元素，并反映真实前后关系。 |
| 保存固定 | 保存当前断点布局并退出编辑，隐藏工具与选框、恢复按钮/链接/表单操作；刷新后保持。 |
| 再次编辑 | 明确可找回的入口，载入已保存位置、图层与锁定状态，接着调整。 |
| 撤销与取消 | 撤销/重做；取消本轮编辑恢复进入时的已保存版本。恢复默认独立操作，可撤销或先保留备份。 |
| 导出 | 导出可校验的布局 JSON，作为迁移、备份及经用户确认后固化到源码的依据。 |

按钮“水平居中”表示元素中心对齐区域的竖直中轴，只改 x，保留 y；“垂直居中”只改 y。不要使用一个含义不明的“水平对齐”按钮代替六种明确命令。

## 集成约束

- 在真实 DOM 上编辑，保留 React/Vue 等现有状态与事件；不得用截图或透明热点替代真实元素。已有 flex/grid 不因加工具而一律改成 absolute。
- 编辑位移使用独立的可组合通道，不能覆盖元素原来的旋转、缩放、居中 transform 或动画。任何包裹层都要验证选择器、布局和 stacking context 是否变化。
- 工具面板位于区域外或独立工具层，可收起；手机可用独立固定尺寸 iframe 工作台。框架内实际 viewport 决定断点，不能只给桌面页面外面套一个窄边框。
- 编辑模式阻止拖动误触跳转/提交；预览和固定模式恢复原交互。工具、遮罩和选框不能进入业务元素清单或挡住页面操作。
- 布局按项目、页面、区域、断点、基线版本隔离。沿用项目断点，手机和桌面互不覆盖；切换断点时保存草稿并结束当前拖动。
- 默认作为当前开发项目的本地工具接入，读取布局与编辑入口都受相同环境条件约束。用户明确要公开/后台编辑器时，按现有身份、写入权限与持久化架构实现，不能把 localhost 限制强加给产品需求。
- “固定”是保存并停止编辑，不等于写进源码或部署。只有用户要求固化时才将确认版本映射为项目布局配置/CSS，并更新基线版本，避免旧偏移二次叠加。发布沿用目标项目已有授权流程。

## 完成与汇报

跑完验收参考中与实现相关的真实路径。尤其要证明元素彼此对齐、实际遮挡顺序、刷新恢复和再次编辑，不能仅凭存在按钮或截图认定完成。

交付当前可访问的编辑链接、干净预览链接、已登记元素范围、布局保存位置/作用域、验证结果和明确未完成项。若只能完成部分能力，逐项标出，不能把“Skill 已写好”或“构建成功”说成目标网站编辑器已可用。

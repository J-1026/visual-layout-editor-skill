# 真实路径验收

实现编辑器后，用真实浏览器事件验证。几何与持久化可做单元测试，但不能代替下列 UI 路径。测试使用独立浏览器配置或临时页面/存储作用域，不能污染用户已摆好的坐标；结束后清除本次测试数据。

## 开发目标校验

先验证工作树、页面源码和预览进程对应关系，并记录本任务正在开发的页面。只有一个外部 URL 时不得假装已具备编辑目标；用历史页、代理页、克隆页或另建演示页代替当前开发页，验收直接不通过。

## 覆盖与原样保留

- 对照开始时元素清单：所有要求的可见元素可点选或在层级树选中；伪元素、SVG/Canvas 内部对象分别标明支持粒度。
- 相同 viewport 的前后实页：未操作对象的位置、字体、颜色、文案和组件引用保持；区域外元素不变。
- 至少测试一个嵌套组及内部按钮，选择父级和子级分别移动，多选不双重偏移。

## 必测用户路径

1. **拖拽与输入**：选元素拖动已知距离，重测 x/y；缩放工作台后重复，滚动后重复；触摸路径与拖出边界释放均能收口。Escape/pointercancel 恢复当前拖动起点。数值输入和键盘精调生效，表单编辑不被快捷键劫持。
2. **画布对齐**：偏移的对象执行六种命令，重测对应边/中心，误差 <= 1 CSS px；水平命令 y 不变，垂直命令 x 不变。多选整体居中后内部距离不变。
3. **相互对齐**：选择不同宽高的三个元素，以一个为关键对象分别做六种对齐；关键对象不动，其他元素满足几何公式。切到选区参照后验证起始包围盒被冻结。对象已经带增量时再次对齐不漂移。
4. **等距**：三个不同宽度/高度对象分别水平/垂直分布，检查间距相等、首尾边界固定、另一轴不变；空间不足和锁定目标有明确反馈。
5. **层级**：让两个半重叠对象分别上移、下移、置顶、置底，检查实际遮挡和命中对象变化；面板能选底层对象。再测祖先有 transform 的对象，不能只断言 z-index 数字。多选重排保留内部顺序。
6. **保存与再编辑**：移动、对齐、排序和锁定后固定 → 工具隐藏 → 原按钮/搜索真实可用 → 刷新位置与层级保留 → 再次编辑继续调整 → 取消后回到固定版本 → 再编辑并固定第二版，刷新恢复第二版。
7. **断点隔离**：桌面保存 A，手机保存 B，切回桌面仍是 A；改变同一 profile 宽度与跨断点测试，布局不产生意外溢出或串位。固定手机 iframe 时核对内层实际 viewport。
8. **失败与恢复**：模拟存储写入失败，固定不能显示成功，草稿可导出。损坏 JSON/错误基线/其他区域导入不会覆盖有效保存；两个标签版本冲突不会静默丢失任一草稿。
9. **重置与撤销**：一整次拖动/对齐/图层操作各占一个 undo，redo 能还原；恢复默认只重置当前 profile，取消不会覆盖 saved。
10. **环境与固化**：本地工具在非启用环境不加载用户偏移也不出现编辑层；用户要求产品编辑器时验证对应角色权限。若本轮固化源码，使用空存储和旧存储分别验证没有二次叠加。

## 输出证据

报告包括：编辑/预览 URL、实际 viewport、元素登记数量与例外、关键几何 before/after、遮挡验证、保存刷新再编辑结果、文件改动清单和未验证项。截图保留桌面/手机及必要交互状态；动态路径记录操作与断言。

以下不构成通过：存在菜单文案、坐标显示变化、z-index 变大、存储 API 未抛错、页面 HTTP 200、只有构建成功。

如果当前交付只是创建本 Skill，验证文件结构、引用、自包含性与需求覆盖即可；不得虚构上述编辑器运行证据，也无需擅自改造某个网站来测试 Skill。

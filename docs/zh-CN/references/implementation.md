# 交互与数据规范

用于实施编辑器；按目标框架复用状态与渲染机制，不强制引入新的 UI 库。

## 坐标与选择

每个对象有独立、稳定的 ID，不用文本、数组下标或每次渲染随机值。ID 在同一 profile 唯一；重复命中时先消歧，不能悄悄同时移动多个节点。隐藏节点保留数据，不参与当前几何测量。

以区域的约定内容框为坐标空间，明确是否包含 padding。读取实际矩形后统一转换到该空间；不要混用 viewport 的 clientX、document 的 pageX 和 offsetParent 坐标。

普通无旋转画布的屏幕增量 `(dx, dy)` 转换为本地增量 `(dx / scaleX, dy / scaleY)`。嵌套缩放/旋转需要逆变换矩阵；滚动、字体/图片加载、resize 后重测。无法正确转换的形变明确禁止本次操作，不用近似值保存。

拖拽默认支持自由定位，不能未经约定裁掉原本越界的装饰。用户要求限制边界时，对整组包围盒施加同一个裁切位移，保留组内间距；超大对象或互相冲突的约束须解释。

点击选中，Shift/多选按钮切换选择；触屏用明确的多选模式。面板层级树可以选中遮挡对象、组和内部节点；框选属于可选增强。跨组多选允许位置对齐，但祖先/后代选择须消除重叠；锁定对象不可被拖动或作为移动目标，可作为关键参照。

## 拖动事务与业务事件

记录 pointerId、起点、初始位移、初始选择快照；使用 Pointer Events 和 pointer capture 或同等可靠机制处理离开元素后的拖动。一次拖动只生成一个 undo 条目，不按每帧堆历史。

pointerup 完成草稿事务；pointercancel、失焦或 Escape 取消当前拖动并恢复拖动前状态，清除拖拽标记，不能留半拖动状态。编辑手柄设置合适的 touch-action，不能禁止整个页面滚动。释放后不能触发链接或表单提交。

祖先位移后子项相对偏移保持不变。移动多选组时，在一致坐标空间计算同一增量，再映射各自变换空间。

键盘每次默认 1 CSS px，Shift 默认 10 CSS px；若项目已有约定沿用。输入法、contenteditable、表单输入及快捷键冲突须避开。

## 确定性对齐

以下矩形均已转换至统一画布坐标。元素为 `(x, y, w, h)`，参照为 `(rx, ry, rw, rh)`：

| 命令 | 新位置（另一轴保持不变） |
| --- | --- |
| 左对齐 | x = rx |
| 水平居中 | x = rx + (rw - w) / 2 |
| 右对齐 | x = rx + rw - w |
| 顶对齐 | y = ry |
| 垂直居中 | y = ry + (rh - h) / 2 |
| 底对齐 | y = ry + rh - h |

若数据存的是基线增量，将上式目标与当前实际位置相减，再加到当前增量；不能把绝对坐标直接写入 dx/dy。

- 相对画布：参照是约定区域框。多选默认作为一个整体包围盒对齐，保留内部位置；逐元素居中应为明确的另一操作，避免重叠。
- 相对元素：用户选定关键元素并显示标记，关键元素不动，其余元素分别对齐它。若默认最后选中为关键对象，面板明确显示并允许切换。
- 相对选区：操作开始时冻结整个选区包围盒，每个对象分别对齐该矩形。不能边移动边重算参照造成漂移。
- 像素验收以实际 DOM 重测为准，容差 <= 1 CSS px；不要直接把状态标签设置成“误差 0”当作验收。
- 引导线显示画布/参照元素的边和中心；可选吸附默认约 6 屏幕 px，换算到画布单位。显式对齐不依赖吸附，吸附不能偷改另一个轴。

水平等距：按左边位置排序、相同位置以稳定 ID 打破平局，固定首元素左边与末元素右边。`gap = (right(last) - left(first) - sum(widths)) / (n - 1)`，依次累加宽度和 gap 设置 x；y 不变。垂直对应高度和 y。n < 3 不启用；gap < 0 默认不执行，提示空间不足。包含会被移动的锁定对象时禁用并说明，不静默解锁。

## 真实图层

维护同一可排序作用域中从底到顶的稳定 ID 顺序。上移/下移与相邻对象交换，置顶/置底移动到端点，边界操作无变化。多选按当前相对顺序作为一个块移动，不翻转内部顺序。保存并恢复顺序和锁定状态。

先检查祖先的 transform、opacity、filter、isolation、定位与 z-index 等堆叠上下文。子元素的巨大 z-index 无法越过祖先，浏览器 top layer 也不受普通 z-index 控制。数值变化但遮挡不变属于未完成。

优先在不改变基础视觉/流式布局的前提下让需要互相排序的视觉对象处于共同堆叠上下文；或调整明确的可排序父层。不能默认重排 DOM 来调层，因为这可能改变 grid/flex 顺序和键盘阅读顺序。必须重组时，先在独立候选验证坐标、业务状态和可访问顺序。

无法跨越的上下文在面板显示排序范围并禁用不可能的命令；若用户要求任意对象前后互换，该限制意味着对应项尚未完成，需做适配。工具层和模态层不属于用户内容排序范围。

## 状态、保存与恢复

使用明确的 `baseline`、`saved`、`draft` 三份状态：

| 操作 | 行为 |
| --- | --- |
| 普通预览/刷新 | 只应用有效 saved，不把未固定草稿当作定稿。 |
| 开始/再次编辑 | 将 saved（没有则 baseline）复制到 draft；出现选框和工具。 |
| 拖动、对齐、改层级 | 修改 draft；记录一次完整事务，允许 undo/redo。 |
| 固定当前布局 | 校验并持久化 draft，成功后替换 saved、退出编辑和恢复业务事件。 |
| 保存失败 | 留在编辑态，保留 draft，显示失败并可导出；禁止显示“已固定”。 |
| 取消编辑 | 恢复进入时 saved；本轮草稿不污染固定版。 |
| 恢复默认 | draft 回到当前 baseline，可撤销；固定前不覆盖 saved。 |
| 切换断点 | 保存到该 profile 的草稿槽，结束拖动；新 profile 读取自身 saved/draft，明确未固定状态。 |

可用以下 JSON 作为按项目适配的最小模型：

```json
{
  "schemaVersion": 1,
  "projectId": "project-key",
  "pageId": "/landing",
  "regionId": "hero",
  "profile": "mobile",
  "baselineVersion": "layout-1",
  "coordinateMode": "baseline-delta-css-px",
  "canvas": { "width": 390, "height": 844 },
  "elements": {
    "title": { "dx": 0, "dy": -12, "locked": false },
    "art": { "dx": 16, "dy": 0, "locked": false }
  },
  "layerOrder": { "hero-content": ["art", "title"] },
  "updatedAt": "2026-01-01T00:00:00Z"
}
```

- 存储键包含 project/page/region/profile/baselineVersion，saved 与 draft 使用独立槽。示例日期和 ID 不得照抄为真实元数据。
- 保存的是有限数值、布尔值、登记 ID 和合法顺序；不接收任意 CSS、HTML、可执行表达式或外来选择器。
- 本地工具可用 localStorage；它只对当前浏览器配置及 origin 有效（协议、主机、端口均有关），不代表多设备同步。跨设备/多人保存用项目已有后端，身份和并发写入由该后端处理。
- 捕获 quota/访问失败；写入成功后读取并校验。多标签编辑用修订号或同等冲突检测，发现保存版本已变化时保留本地草稿并让用户选择，避免静默覆盖。
- 读取/导入校验 schema、作用域、基线版本、有限数值、ID 唯一性、图层成员完整性和锁定类型。损坏或版本不符的数据保留备份并提示恢复/迁移，不悄悄套用。
- 导出需区分 saved 与 draft；包含所有断点时逐项命名。新增对象用基线，已删除对象作为可解释孤立条目处理，不误套到其他对象。
- 不直接清空整个 localStorage。恢复默认仅作用当前区域/profile；全断点重置需单独明确操作。

## 固化到源码（仅在用户要求时）

从确认后的真实渲染位置和有效模型核对数值，映射为组件布局配置或响应式 CSS，尽量保留原布局机制。不得把缩放工作台上的屏幕坐标当 CSS 坐标，也不能只从一个可能过期的 localStorage 键猜定稿。

合入新的基线后，为相关 profile 更新 baselineVersion 并迁移/归零旧增量；其他 profile 不受影响。验证关闭编辑器、空存储、新刷新与旧保存数据恢复时都没有二次位移。部署是独立动作，遵循项目授权。

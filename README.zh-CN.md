# 开发中页面布局编辑器

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md)

**把正在开发的前端页面，变成可以亲手拖动、对齐和保存布局的工作区。**

这是一个 Agent Skill：让编程 Agent 在当前项目的真实源码页面中接入布局编辑控件。你亲自摆放元素，Agent 负责接入、验证与可靠保存。

![SkillGuide 真实开发页面全页截图](media/skillguide-full-page.png)

## 能做什么

- 拖动已登记的文字、按钮、图片、装饰和容器，输入 x/y 精调。
- 相对区域居中，或让多个元素彼此对齐、等距排列。
- 在有效图层范围内上移、下移、置顶、置底，选择被遮挡对象。
- 固定保存、刷新恢复、再次编辑、取消、撤销重做、导出布局 JSON。
- 桌面与手机布局分别保存；可要求编辑控件使用简中、英文或繁中。

## 适用边界

必须是**当前正在开发、可修改源码的项目页面**。预览链接只是用来定位项目，不是随便丢一个网址就能编辑。它不是浏览器扩展或在线拖拽平台；安装 Skill 后，Agent 还需要在指定页面源码中完成接入。

“固定当前布局”不等于写入源码、发布上线或跨设备同步。你确认摆放结果后，可以另行要求 Agent 固化到源码。

## 安装

在 GitHub 下载仓库 ZIP，将其中的 **`skills/visual-layout-editor` 文件夹**放入 Agent 的技能目录。Codex 默认目录为 `~/.codex/skills`；配置了 `CODEX_HOME` 时使用其 `skills` 子目录。文件夹名称保留为 `visual-layout-editor`，已有同名版本先备份。当前会话未识别时，新开会话并按名称调用。

其他 Agent 的安装路径与发现机制可能不同，尚未逐一验证跨 Agent 兼容性。

## 调用示例

打开正在开发的项目后，对 Agent 说：

> 使用 $visual-layout-editor，把当前正在开发的技能包详情页接入布局编辑。标题、来源信息和成员卡片都能拖动，可以相互对齐、调整图层、固定保存和再次编辑。控件用中文，打开真实预览让我自己调整。

也可以指定首页首屏、某个详情区域或一组卡片。Agent 先复用现有组件接入编辑器，再由你亲手调整；需要固化源码时另行提出。

## 实测与限制

截图来自 SkillGuide 真实开发中的技能包详情页，共35个可选对象。已通过 Chrome 实际验证：拖拽、区域居中、关键元素对齐、同父级遮挡顺序、保存刷新、再次编辑取消，以及桌面与手机断点保存隔离。

本次试用图层排序限同一父级，跨父级尚未实现。真实触屏硬件、存储异常/冲突恢复、JSON 实际下载尚未验证。Skill 中的验收要求不代表所有项目都已经实测通过。

发行包包含 Skill 指令与参考规范，不包含 SkillGuide 网站源码或独立编辑器运行库。多语言指文档与可要求的编辑控件语言，不会自动翻译网页业务内容。
